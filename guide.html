Login & Access

1. Founder / Investor Login

After submitting an application/form, use Google Login to access your personal dashboard.

  • Click "Track My Application" in the menu or the "Dashboard" button in the navbar
  • Sign in with your Google account (Gmail)
  • You'll see your submitted application and its current status

2. Admin Login

Administrators use email/password (Google login is not used).

  • Direct URL: /dashboard/admin.html
  • Credentials are managed separately — contact Ideacubator team for admin account setup
  • Once logged in, you'll see the admin dashboard with applications and investor inquiries
Note: Admin and user dashboards are separate. Admin cannot log in via Google; founders/investors cannot access admin pages.

How to Apply (Founders)

  1. Click "Have an Idea" button on the homepage
  2. Select your profile — choose from 9 tiles:
    • College Student
    • Employed Professional
    • MVP Built
    • Revenue Startup
    • Sell My Business
    • IPO Preparation
    • Market Validation
    • Company Valuation
    • Go Global / Enter India
  3. Fill the form — required fields marked with *
  4. Check the declaration at the bottom
  5. Submit — you'll see a confirmation message

After submission, log in with Google to track your status in the dashboard.

Admin Dashboard Guide

What You Can Do

  • View all applications — see who applied, their profile type, and status
  • Filter by status — use the dropdown in each row to change status
  • Open Details modal — click "Details" to see full application data
  • Review & Comment — add internal notes and update status from the details modal
  • View investor inquiries — see who wants to invest and approve/reject

Review Workflow

  1. Find the application in the Applications tab
  2. Click Details to open the full view
  3. Read the founder's information
  4. In the Review Actions panel:
    • Select new status from dropdown (Under Review, Approved, Rejected, etc.)
    • Add comments (optional but recommended)
    • Click Save Review
  5. The status updates immediately and is visible in the main table
Important: Use the status dropdown in the Details modal to change status — not the one in the table. The table dropdown is for quick updates only in some versions.
